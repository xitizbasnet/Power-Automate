# 📧 Power Automate

## Schedule Email with OneDrive File Attachment

**Date:** 6/2/2025

**Prepared By:** Xitiz Basnet

---

# 📘 Overview

## 🎯 Objective

This guide outlines the steps to create an automated scheduled email using **Microsoft Power Automate** that sends a specific file stored in **OneDrive for Business** to a designated recipient every hour.

---

# 🔧 Pre-requisites

Before starting, ensure the following requirements are met:

* Access to **Microsoft Power Automate**
  🔗 [https://make.powerautomate.com](https://make.powerautomate.com)
* **OneDrive for Business** with the target file stored
* Access to **Office 365 Outlook**
* Valid recipient email address

---

# ⚙️ Step-by-Step Instructions

---

## 1️⃣ Log In to Power Automate

* Navigate to:
  🔗 [https://make.powerautomate.com](https://make.powerautomate.com)
* Sign in using your organizational account.

---

## 2️⃣ Create a Scheduled Flow

* In the left navigation menu, click:

```text id="pa1"
+ Create
```

* Select:

```text id="pa2"
Scheduled cloud flow
```

* Configure the flow:

### Flow Details

* **Flow Name:** `Hourly Daily Work Update`

### Schedule Configuration

* **Start Date:** 6/2/2025

* **Start Time:** 9:00 AM

* **Recurrence:** Every 1 hour

* Click **Create**

---

## 3️⃣ Configure the Recurrence Trigger

After creation:

* The **Recurrence trigger** is automatically added
* Verify interval is set to **1 hour**

---

## 4️⃣ Get File Content from OneDrive

* Click:

```text id="pa3"
+ New step
```

* Search:

```text id="pa4"
Get file content
```

* Select:

```text id="pa5"
OneDrive for Business
```

### File Selection

* Click folder icon and select the file:

```text id="pa6"
/Send Daily Excel Report/Send Daily Excel Report.xlsx
```

### Settings

* **Advanced Parameters:** Leave blank
* **Infer Content Type:** Yes

---

## 5️⃣ Send Email with Attachment

* Click:

```text id="pa7"
+ New step
```

* Search and select:

```text id="pa8"
Send an email (V2)
```

(Office 365 Outlook)

---

### Email Configuration

#### 📩 To

* Enter recipient email address

#### 📝 Subject

```text id="pa9"
Hourly Daily Work Update
```

#### 📄 Body

* Enter the required message content

---

### 📎 Advanced Options (Attachments)

* Expand **Advanced options**
* Configure:

#### Attachment Name

```text id="pa10"
Hourly Daily Work Update Excel File.xlsx
```

#### Attachment Content

* Select output from:

  * **Get file content (OneDrive step)**

---

## 6️⃣ Save and Test the Flow

### Save

* Click:

```text id="pa11"
Save
```

### Test

* Click:

```text id="pa12"
Test
```

* Select:

  * **Manually**
* Click **Test**
* Click **Run Flow**

---

### Verification Steps

* Wait for **Success message**
* Check recipient inbox for email delivery
* Click **Done**

---

## 7️⃣ Completion and Verification

* Return to Power Automate dashboard
* Confirm flow status shows:

```text id="pa13"
✔ Green Checkmark (Active)
```

This indicates:

* Flow is active
* Scheduling is correctly configured
* Automation is functioning properly

---

# 📌 Conclusion

You have successfully created and tested a scheduled Power Automate flow that:

* Runs every hour
* Retrieves a file from OneDrive
* Sends it via email using Outlook
